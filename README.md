# Desbravando o Universo Bat 🦇

![Batch](https://img.shields.io/badge/Batch-Scripting-blue?style=for-the-badge&logo=windows&logoColor=white)

Bem-vindo ao centro de comando de automação com arquivos `.bat`. Este repositório é o seu guia prático para dominar a sintaxe do Windows, desde diagnósticos simples até automações complexas.

---

## 🧭 1. Como Estudar por Aqui?

Siga a esteira de aprendizado para consolidar seus conhecimentos:

```mermaid
graph LR
    A[1. Fundamentos] --> B[2. Automações Simples]
    B --> C[3. Projetos Técnicos]

````
---

## 🗺️ 2. Navegação no Repositório

Organizamos o conteúdo de forma progressiva para guiar seu aprendizado do zero ao nível avançado:

| Categoria | O que você irá encontrar |
| :--- | :--- |
| **📁 01_Fundamentos** | A base de tudo: comandos nativos, variáveis, condicionais e a lógica por trás de cada instrução. |
| **📁 02_Automacoes** | Scripts práticos voltados para tarefas de TI, como logs, diagnósticos de sistema e organização de arquivos. |
| **📁 03_Projetos** | Soluções técnicas robustas que integram automação, manipulação de janelas e APIs do Windows. |
| **📁 04_Comunidade** | Seu laboratório de estudos: espaço dedicado para você aplicar o que aprendeu e testar suas próprias criações. |

> **Dica:** Siga a ordem das pastas conforme a tabela acima para garantir uma curva de aprendizado sólida. Dentro de cada pasta, você encontrará um arquivo explicativo com os objetivos e desafios de cada nível.
